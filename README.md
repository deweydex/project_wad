# Web Authoring Project Starter

A five-page skeleton for the Web Authoring project brief: a complete
website of five or more pages, on a topic of your own choosing, different
from your first assignment.

**Start with `planning.md`, before you touch any HTML or CSS.** It walks
through the questions the brief marks under "Planning & Preparation," and
answering them first makes the building phase faster.

## What's here

- `index.html`, `about.html`, `gallery.html`, `contact.html`,
  `resources.html` — five pages with the structure the brief requires
  (semantic HTML, a table, both list types, a form, images with alt
  text), placeholder content marking where yours goes.
- `styles.css` — one stylesheet, linked from every page. It has just
  enough CSS to make Flexbox, Grid, a media query, and link states work;
  the colours, fonts and personality are for you to add.
- `planning.md`, `readme.md`, `maintenance.md` — the three documents the
  brief asks for, as templates. `readme.md` becomes your own site's
  `README.md` once you rename this one out of the way (or delete this
  one and rename `readme.md` up).

## Getting your own copy

Either **Use this template** (the green button above) or **Fork**. Both
give you your own repository; a template copy has no visible link back
to this one, which suits a project you might want to keep past the
course. Either way, rename it to whatever you like — this repository's
own name says which class it is for, but yours does not have to.

## What the brief requires, in one place

Across the whole site: semantic HTML5, a full document structure on
every page, a sensible heading hierarchy, both list types, at least one
data table, images with real alt text, internal links connecting every
page, at least one form, and at least one HTML character entity (`&copy;`
in the footer already counts, but find at least one more).

In the stylesheet: element, class and ID selectors, Flexbox somewhere,
Grid somewhere, typography and colour choices that are yours, borders and
border-radius, padding and margins, link pseudo-classes, consistent
navigation, and a media query.

The full brief, with the assessment criteria, is in your course
materials.
